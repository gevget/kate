# Екатерина Романова — стоматолог

Одностраничный сайт Екатерины Романовой — врача-стоматолога для взрослых и детей.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Публикация

После отправки изменений в ветку `main` сайт автоматически собирается и публикуется на GitHub Pages.

Адрес сайта: https://gevget.github.io/kate/
